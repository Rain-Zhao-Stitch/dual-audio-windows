# Dual Audio

Windows 10/11 小工具：将一个播放设备上的系统声音实时镜像到另一个播放设备，分别调节两边的音量，并为设备 2 添加 0–1000 ms 可调延迟。音量和延迟同时支持滑块与直接数字输入。

界面采用完整深色模式：深色标题栏、黑灰卡片、绿色强调色和自绘滑条。

设备 1、设备 2 的音量是独立系数，总音量是两台设备共用的乘数。系统设备音量 = 设备系数 × 总音量 ÷ 100；总音量调整同时更新两个系统设备，系统音量调整反算对应系数并保持总音量不变。声卡有硬件取整步进时，以其可表示值为准。程序不改写各应用的音量或静音。

点击窗口右上角关闭按钮时，程序会隐藏到系统托盘，正在进行的同步播放不会中断。右键托盘图标可直接调整总音量、设备 1 音量和设备 2 音量；双击图标可恢复窗口，只有选择“退出程序”才会完全退出。

同步成功后接管音量加、音量减和静音键，让它们控制两台设备共用的总音量，并显示音量浮层；停止后恢复系统默认行为。系数支持大于 100%，总音量不能超过任一设备达到系统 100% 的上限。总音量为零后在系统里调高音量，会恢复总音量到 100% 并反算系数。

## 使用方法

1. 先在 Windows 声音设置中确认两个输出设备均已连接、启用。
2. 打开 `Dual Audio.exe`。
3. “设备 1”选择当前播放系统声音的设备（通常标有“系统默认”）。
4. “设备 2”选择另一个扬声器或耳机。
5. 点击“开始同步播放”。音量和设备 2 延迟都可使用滑块调整，也可点击右侧数字框直接输入；播放中修改会立即生效。
6. 随时按 `Alt + Insert` 快速开始或停止同步；窗口隐藏到系统托盘后仍然有效。
7. 持续播放有人声或节奏变化的音乐后，点击“麦克风自动校准”。程序分别隔离两台设备并录音、再同时播放复核，两轮一致后临时加入正向补偿验证，通过才保存。约 75–90 秒，可取消；只校准设备 1 直出、设备 2 镜像方向，不自动设置负延迟。

校准使用真实同步链路，不把直接播放响应差遗漏镜像耗时后填入滑条。临时端点静音和验证用延迟会在正常结束、取消或失败时恢复；不修改应用合成器音量。若原来没有同步，校准期间临时启动、结束后停止。没有有效播放或无法可靠复核时保持原延迟。

设备 1 是声音来源，因此播放器、浏览器或游戏的声音必须先被 Windows 路由到设备 1。程序无需管理员权限。

## 注意

- 蓝牙设备会有硬件和编码延迟，两个设备之间可能存在轻微时间差。
- 程序只能增加设备 2 的延迟。建议把较慢的设备设为设备 1，再给较快的设备 2 增加延迟。
- 切换 Windows 默认设备、插拔耳机或断开蓝牙后，请停止并点击“刷新设备”。
- 为避免回声或啸叫，不要把麦克风监听功能同时打开。

## 从源码构建

需要 .NET 8 SDK：

```powershell
dotnet restore
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```
